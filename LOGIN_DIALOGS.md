# PearPortOS Catalina Login & Dialogs (v0.5.7)

The web edition stores a browser-local demonstration account. It does **not** authenticate with macOS, elementary OS, Linux, or GitHub, and does not grant permissions to real apps.

After first-run setup, one stored account is shown directly with its password field at startup, lock, logout, and restart. Correct password signs in automatically, without pressing Enter. The original account and saved virtual files remain unchanged.

The password screen uses the selected Day/Dusk/Night or custom wallpaper, rather than switching the wallpaper when a user is selected. The account-help button does not promise a recovery key: password recovery is not implemented.

System Preferences > General > Alerts includes a Catalina warning and authentication demo. Software Update and Security & Privacy also include a dialog preview. Authentication in the demo validates only the browser-local PearPortOS password and has no privileged effect.

Virtual Pearder Delete, Empty Trash, Get Info and PearPortOS Restart use Catalina-style alert/confirmation dialogs.

Avoid using your real computer password for this web-only preview.
